# Ria's Creations Salon: website demo

A one-page website mock-up to show Ria (Lilburn, GA). No install needed.

**To open it:** double-click `index.html`. It opens in your web browser.
Fonts and the map need internet; everything else works offline.

## Add the lounge photo

Save the waiting-lounge photo (brown chairs, olive tree, lit oval mirror) as
`images/lounge.webp`. The "Book a visit" card uses it. Until then, it shows the studio photo.

## What's on the page

1. **Hero**: headline and a lit arched-mirror photo. The rating, address, hours and the Call / Book buttons sit in a quiet bar at the bottom.
2. **About**: short intro and the styling stations photo.
3. **Services**: tabs for Hair, Brows and face, Facials, Wax and massage.
4. **Reviews**: three real Google quotes you can drag or swipe through.
5. **Book a visit**: lounge photo card and a request form (demo only: nothing is sent).
6. **Visit**: address, phone, hours and a map.

There is a day/evening switch in the top bar.
